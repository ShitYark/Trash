# Именование: коммиты и ветки

Единый источник правды для всего, что агент **предлагает или создаёт** с именем: сообщение коммита, имя ветки. Читается в момент формирования имени (лениво, в автозагрузку не входит).

## Сообщение коммита

**Формат — ровно такой:**

```
Добавлен поиск больших файлов в Загрузках
```

Обязательные правила:

1. **Ключей задач нет.** Проект без трекера: сообщение — сразу суть, без префиксов и квадратных скобок.
2. **Только одна строка** — заголовок. **Тело коммита не пишем**: ни списков изменений, ни объяснений. Всё это видно в диффе, плане и истории модуля.
3. **Никаких упоминаний AI-агента**: `Co-Authored-By: Claude …`, `Generated with …`, эмодзи-подписи — **запрещены**. Автор коммита — человек. Отключено и настройкой `includeCoAuthoredBy: false` в `.claude/settings.json`.
4. **Формулировка — завершённый результат**, а не команда и не инфинитив:
   - ✅ `Исправлено…`, `Реализовано…`, `Добавлено…`, `Добавлены…`, `Обновлена…`, `Убрано…`
   - ❌ `Исправить…`, `Реализовать…`, `Добавить…`, `Фиксим…`, `Правка…`
5. **Сообщение = заголовок записи истории модуля.** Ключа задачи нет, поэтому связь «коммит ↔ запись истории» держится на совпадении текста: запись `#### 2026-10-12 — Добавлен поиск больших файлов` находится коммитом через `git log --grep "Добавлен поиск больших файлов"`. Не перефразируй строку между историей и коммитом.
6. **Отдельные коммиты:**
   - правки истории модулей (архивация, перегенерация) — отдельным коммитом с пометкой `[skip-doc-check]` в конце строки;
   - правки самого flow — отдельно от правок кода.

Примеры:

```
Добавлена категория «Кэши Homebrew»
Исправлен подсчёт размера папок с симлинками
Архивирована история модуля cleanup: записи старше 6 месяцев [skip-doc-check]
```

## Имя ветки

Основная ветка — `main`. Ветку под задачу заводит пользователь, когда считает нужным; имя — kebab-case латиницей по сути задачи: `large-files-finder`, `fix-symlink-size`.

## Кто коммитит

Коммиты и пуш делает **пользователь** — агент только предлагает готовую строку сообщения.

- `git commit` в основном дереве блокирует guard-хук. Пользователь явно попросил закоммитить в чате — повтори команду с `FLOW_ALLOW_COMMIT=1`.
- `git push` агент не делает никогда.
