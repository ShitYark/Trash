# Перенос Claude-flow из WhiteBox iOS

## Проблема

Новый проект без правил работы агента: нет маршрутизации задач, плана до кода, истории решений, проверок в хуках. В WhiteBox iOS эта система уже отлажена.

## Почему важно

Trash удаляет файлы пользователя. Агент без барьеров — плана, ревью и guard-хука — может сломать защиту удаления или сам удалить реальные данные во время отладки.

## Решение

Перенесено с адаптацией:

| Из WhiteBox | В Trash |
|---|---|
| `AGENTS.md` + мост `CLAUDE.md`, автозагрузка `root-rule` и `response-format` | то же |
| Команды `/dev:code`, `search`, `analyze`, `review`, `history`, `meta`, `artifacts` | те же шаги и остановки; без Jira, заказчиков и worktree |
| Субагенты `context`, `code-reviewer` | `context` работает только с историей; `code-reviewer` с приоритетом безопасности удаления |
| История модулей, порог 44 КБ, архив по кварталам | то же; поле «Заказчик» убрано, добавлено «Решения» |
| Хуки: `guard-bash`, `check-doc-sync`, `check-links`, `check-glossary`, `check-sizes` | то же; guard дополнен запретом `rm` вне проекта |
| `Makefile` как единственный путь сборки | `make build` / `test` / `run` / `flow-check` / `flow-test` |

Решения пользователя:

- **Ключей задач нет.** Коммит — одна строка сути. Связь «коммит ↔ запись истории» — дословное совпадение текста: `git log --grep`.
- **Только Claude Code.** `.agents/` и `.codex/` не переносились.

Не перенесено, потому что не относится к Trash: заказчики и их профили, серверные сеттинги и гейты, брендовые сборки, reportcollector и `/wb:analyse-log`, TeamCity и TestIT, Flutter, ObjC↔Swift, CodeGuard, simulator-seed, протокол worktree, генератор `build-module-history.py` — он завязан на Jira, а история нового проекта пишется по ходу задач.

## Риски

- Ритуал шагов избыточен для мелких правок. Смягчение — условные остановки: вопрос задаётся только при развилке.
- Без ключей задач заголовки записей истории и коммиты могут разойтись, если сообщение перефразировать при коммите.

- [x] Документация трёх модулей и первые записи истории

- [x] `make flow-check` чист, `make build` и `make test` проходят
