# Claude-flow: мета

Документация про сам flow проекта Trash — как агент работает, на каких принципах построен flow, какие правила формата соблюдаются, какие улучшения запланированы.

Flow перенесён из проекта WhiteBox iOS и адаптирован: без ключей задач, без заказчиков, только Claude Code. Решения переноса — [plans/port-whitebox-flow.md](plans/port-whitebox-flow.md).

## Когда заходить сюда

Только при задачах про сам flow:

- изменение инструкций: `AGENTS.md`, `root-rule.md`, команды `/dev:*`, субагенты;
- изменение хуков и скриптов `flow/scripts/`;
- новые разделы документации в `flow/knowledge/**`.

Для обычных задач разработки сюда заходить не нужно — этот раздел не грузится автоматически.

## Точка входа в работу

Изменения flow — командой [`/dev:meta`](../../.claude/commands/dev/meta.md): интерпретация → план → согласование → реализация → проверки → отчёт.
