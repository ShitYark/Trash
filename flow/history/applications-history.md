# История изменений: applications

Хроника правок модуля «Программы». Текущее состояние модуля — [`applications.md`](../knowledge/modules/applications.md). Формат — `flow/meta/conventions.md` → «Формат записи истории модуля».

## Активные записи

#### 2026-10-12 — Программы, принадлежащие системе, удаляются в Корзину через Finder с паролем администратора

- Суть: программы root — из App Store и `.pkg` — удаляются через Finder с паролем администратора, если `NSWorkspace` отказал. Подпись «нужен пароль администратора» теперь соответствует поведению. Подробности и решения — в истории `cleanup`.
- Файлы: `Trash/Services/Cleaner.swift`, `Trash/Services/FinderTrash.swift`

#### 2026-10-12 — Добавлен раздел Программы: удаление программ и поиск остатков удалённых программ

- Суть: пункт «Программы» с разделами «Установленные программы» — удаление только в Корзину — и «Остатки удалённых программ» — данные программ, которых больше нет, в семи папках `~/Library`.
- Решения:
  - Программа и остаток удаляются **узкими правилами**, а не корнями: `/Applications` и папки `~/Library` целиком удаляемыми не становятся. Конфликт с решениями «Терминала» и «Xcode» решён пользователем: вариант «узкое правило + копии Xcode удаляются тем же способом».
  - Остаток — **только имя-идентификатор**; обычные имена папок не трогаются **намеренно**.
  - Group Container с Team ID — по подписи кода установленных программ: общий вход Microsoft не трогается, пока стоит Office.
  - Сами отмечаются только уверенные остатки; файлы настроек — **намеренно** никогда.
  - Запущена — по пути бандла: у копий Xcode один идентификатор.
  - Spotlight отвергнут: эмулятор Android не находит.
- Прогон по реальному диску после ревью, только чтение: 49 программ, 22 ГБ; 126 остатков, 8 ГБ, отмечено 7,96 ГБ — Docker и Whisky. Чужие Group Containers закрыты macOS — «нет доступа». `com.YourCompany.FirstGameGame` отмечен верно: программы и проекта на диске нет, папка с 2024 года.
- Ревью — три High закрыты:
  - группы данных системных программ — «Быстрые команды» `group.is.workflow.*` — сами отмечались как остаток: каталог включает системные программы и группы из entitlements подписи; системные метки исключены в любом месте имени;
  - iOS-программа на Apple Silicon не узнавалась — идентификатор и подпись теперь из `WrappedBundle`;
  - узкие правила `SafetyGuard` не были привязаны к категории — теперь `canDelete(_:as:)`.
  Medium: «macOS помнит программу» — только «проверьте»; вложенные расширения и помощники; тесты стража на ссылку в `/System`, бандл внутри бандла, `~/Applications`-ссылку. Low: пути с `..` отклоняются, «отмечено» не зависит от порядка словаря.
- Тесты: `ApplicationsTests` — 12 сценариев, `CleanupViewModelTests.applicationInTwoSectionsIsSelectedAndCountedOnce`; мутации правила Team ID, групп из подписи, обёртки iOS, привязки к категории, отказа запущенной, перепроверки остатка и ухода копии Xcode в Корзину ловятся.
- Файлы: `Trash/Services/ApplicationCatalog.swift`, `Trash/Services/ApplicationsScanner.swift`, `Trash/Services/URL+Canonical.swift`, `TrashTests/ApplicationsTests.swift`
- План: `flow/plans/applications-section.md`
