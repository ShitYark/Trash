#### 2026-10-13 — Строки, которые нельзя отметить, помечены «только поиск»

- Суть: по просьбе пользователя у строки с неактивным чекбоксом (`!item.isDeletable`) — метка «только поиск» рядом с названием. Касается и неудаляемых элементов удаляемых разделов: встроенный рантайм, cask, явно поставленная формула.
- Решения: метка в строке — серая **намеренно**, чтобы не путать с синим «мусором»; в заголовке раздела «только поиск» остаётся синим.
- Ревью: Low закрыты — подсказка VoiceOver у неактивного чекбокса, комментарий `Badge`, имя `showsJunkBadge`.
- Файлы: `Trash/Views/CategoryDetailView.swift`, `Trash/Views/ThemeComponents.swift`

#### 2026-10-13 — Окно очистки говорит только про отмеченное

- Суть: при одном отмеченном рантайме окно подтверждения говорило про файлы, программы и Корзину — пользователь назвал описание странным. Тексты окна теперь собираются из `cleanupItems` (`CleanupNotes`): подзаголовок «не тронем …» — по видам отмеченного, строки плашки — только про отмеченное, подписи кнопок — с исключениями. Отчёт пишет, куда ушло удалённое, по счётчикам очистки.
- Решения:
  - Одна кнопка «Удалить» — когда всё уходит навсегда при любом режиме, **намеренно** и для одной Корзины: раньше подпись «можно вернуть» у содержимого Корзины была неправдой. Кнопка передаёт режим «в Корзину» **намеренно** — безопасный путь, если сюда попадёт обычный файл.
  - Флаг «последняя очистка — навсегда» удалён: отчёт по нему врал про программы и Корзину.
- Ревью: Medium — «можно вернуть» при отмеченной Корзине — закрыта; Low закрыты — отчёт по составу, режим кнопки, строка про папки без симулятора, лишний `Equatable`.
- Тесты: `CleanupNotesTests` — один рантайм, одна Корзина, папки без симулятора, исключения в подписях, итог отчёта.
- Файлы: `Trash/Views/ConfirmCleanupSheet.swift`, `Trash/Views/CleanupReportSheet.swift`, `Trash/Views/ContentView.swift`, `Trash/ViewModels/CleanupViewModel.swift`, `TrashTests/CleanupNotesTests.swift`, `TrashTests/CleanupViewModelTests.swift`

#### 2026-10-12 — Убраны графики с экранов разделов, ускорена прокрутка списков

- Суть: на экране группы убрана полоса состава с легендой, в строках — полоски размера и подсветка наведения. `ItemRow` получает значения вместо `Binding` и сравнивается по элементу и отметке (`.equatable()`); список явно читает `model.selection`; иконки Finder — из кэша `FileIcons`.
- Решения:
  - Графики на экранах разделов убраны **намеренно** — пользователь назвал их непонятными; полосы остались только там, где есть подписи: «Обзор», карточки групп, виджет диска.
  - Иконка грузится синхронно, но один раз на путь — **намеренно** без асинхронной загрузки: замер ~0,6–0,8 мс на строку, YAGNI.
- Ревью: стенд с той же структурой вью подтвердил — щелчок перерисовывает одну строку, «выбрать всё» — только изменившиеся, повторный скан обновляет строки, лениво строится 12–13 строк из 1000. Low закрыты: правило про `==` в комментарии, лишняя обёртка сводки, явное чтение выбора как страховка для macOS 14–15.
- Тесты: не добавлены — правка вида, логика выбора и удаления не менялась; 73/73.
- Файлы: `Trash/Views/CategoryDetailView.swift`, `Trash/Views/GroupOverviewView.swift`, `Trash/Views/Theme.swift`

#### 2026-10-12 — Очистка и сумма «Отмечено к удалению» учитывают только текущий экран

- Суть: «Отмечено к удалению», окно очистки и `cleanSelected(permanently:)` берут `cleanupItems` — отмеченное в разделах текущего экрана: «Обзор» — все, категория — она, группа — её разделы. Отметки других разделов сохраняются, но не учитываются и не удаляются. Разбивка в окне подтверждения строится из того же списка, что уходит в `Cleaner`.
- Решения:
  - Пользователь попросил, чтобы на экране раздела не учитывались отметки других — **намеренно** по экрану, а не общий выбор: раньше сумма на экране «Программы» могла быть меньше того, что удалит «Очистить».
  - Отметки при переходе не сбрасываются **намеренно** — вернувшись на экран, пользователь видит свой выбор.
  - Копия Xcode входит в область и «Программ», и «Xcode» — отметка общая по URL.
- Ревью: Medium закрыт — разбивка подтверждения могла показать «Программы» на экране «Xcode» для копии Xcode; теперь она строится из `cleanupItems`. Low: подпись «на этом экране», `cleanupScope` вместо повтора `selectedItem ?? .overview`.
- Тесты: `CleanupViewModelTests` — сумма следует за экраном, включая «Обзор» и пустой выбор пункта; очистка на экране Xcode удаляет DerivedData, а отмеченный кэш «Системы» остаётся на диске и в выборе; копия Xcode — в области обоих экранов по одному разу. Мутация «очистка берёт всё отмеченное» ловится.
- Файлы: `Trash/ViewModels/CleanupViewModel.swift`, `Trash/Views/CleanupBar.swift`, `Trash/Views/ConfirmCleanupSheet.swift`, `TrashTests/CleanupViewModelTests.swift`

#### 2026-10-12 — Приложение переведено на новый дизайн: тёмная тема, экран «Обзор», окно очистки и иконка

- Суть: дизайн «Сортировочная» из холста — графит и оранжевый `#FF8A3D`, окно всегда тёмное. Новый пункт и экран «Обзор» — выбран при запуске: «можно освободить», место на диске до и после очистки, полоса «что занимает диск», карточки групп, ход сканирования. Своя боковая панель со знаком и виджетом диска; экраны категории и группы — карточки с полосой размера в строках. Подтверждение, ход очистки и отчёт — одно окно. Иконка — вариант А «Бак с полосами».
- Решения:
  - Окно **намеренно** всегда тёмное — светлой темы в дизайне нет.
  - Шрифты системные — **намеренно**, по решению пользователя: шрифты холста не встраиваются.
  - Боковая панель — свои кнопки вместо `List` **намеренно**: точный вид из дизайна; стрелки ↑/↓ пункты не переключают.
  - Окно очистки одно **намеренно**: второй sheet после закрытия первого мог не открыться, если очистка быстрее анимации.
  - У кнопок удаления по-прежнему нет шорткатов; «Отмена» — Esc, «Готово» — Return.
- Ревью: High закрыт — место на диске не перечитывалось, `URL` кэширует значения ресурсов; кэш сбрасывается перед чтением. Medium закрыты — у чекбокса строки появилось имя для VoiceOver; отчёт больше не теряется между двумя sheet. Low закрыты — склонение «объектов», разбивка подтверждения без двойного счёта копии Xcode, списки групп из `CategoryGroup.allCases`, декоративные иконки скрыты от VoiceOver, цвета в `Theme`.
- Тесты: `CleanupViewModelTests` — «Обзор» выбран при запуске; «найдено» считает копию Xcode один раз; «только поиск» отдельно от «можно освободить»; место на диске читается при скане и после очистки.
- Файлы: `Trash/App/TrashApp.swift`, `Trash/ViewModels/CleanupViewModel.swift`, `Trash/Views/ContentView.swift`, `Trash/Views/SidebarView.swift`, `Trash/Views/OverviewView.swift`, `Trash/Views/CategoryDetailView.swift`, `Trash/Views/GroupOverviewView.swift`, `Trash/Views/CleanupBar.swift`, `Trash/Views/ConfirmCleanupSheet.swift`, `Trash/Views/CleanupReportSheet.swift`, `Trash/Views/Theme.swift`, `Trash/Views/ThemeComponents.swift`, `Trash/Services/DiskSpace.swift`, `Trash/Assets.xcassets`, `TrashTests/CleanupViewModelTests.swift`
- План: `flow/plans/main-window-design.md`

#### 2026-10-12 — Раздел Xcode собран в один пункт боковой панели, исправлен двойной учёт жёстких ссылок

- Суть: боковая панель стала плоской — Кэши приложений, Журналы, Корзина, Xcode. 12 разделов Xcode переехали в окно пункта «Xcode» (`XcodeOverviewView`): сводка «Найдено / Отмечено к удалению», разделы `DisclosureGroup` по убыванию размера с чекбоксом «выбрать всё» и меткой «только поиск». Выбор, очистка и подтверждение не менялись.
- Решения:
  - Пользователь попросил Xcode **одним пунктом** боковой панели — секции «Система» / «Xcode» в боковой панели убраны.
  - Разделы свёрнуты по умолчанию и отсортированы по размеру, не по фиксированному порядку.
  - «Отмечено к удалению» и чекбоксы разделов — только по удаляемым элементам.
- Ревью: Medium закрыт — частичный выбор в свёрнутом разделе выглядел пустым; теперь смешанный чекбокс `Toggle(sources:)` и «отмечено N» в заголовке. Low: «нет данных» вместо нулевого размера, замок при отказе в доступе, порядок разделов не прыгает во время скана, пустое место вместо невидимого чекбокса для VoiceOver, удалены неиспользуемые свойства view model.
- Тесты: `CleanupViewModelTests` — сводка Xcode считает отмеченным только удаляемое; у раздела «только поиск» нет «выбрать всё»; частичный выбор виден в сумме раздела.
- Файлы: `Trash/ViewModels/CleanupViewModel.swift`, `Trash/Views/SidebarView.swift`, `Trash/Views/ContentView.swift`, `Trash/Views/CategoryDetailView.swift`, `Trash/Views/XcodeOverviewView.swift`, `Trash/Views/CleanupViewModel+Bindings.swift`, `TrashTests/CleanupViewModelTests.swift`

#### 2026-10-12 — Создан каркас приложения: сканирование, очистка и главное окно

- Суть: окно на `NavigationSplitView` — боковая панель категорий с размерами, список элементов с чекбоксами и «Выбрать всё», нижняя панель «Выбрано / Очистить», диалог подтверждения, алерт отчёта, баннер Full Disk Access. Состояние — `CleanupViewModel` (`@MainActor @Observable`).
- Решения:
  - Автоскан при запуске; под тестами отключён по `XCTestConfigurationFilePath`.
  - У кнопки «Очистить» **намеренно нет** клавиатурного шортката: двойной Return не должен удалять файлы.
  - Подтверждение всегда спрашивает режим удаления, отдельного экрана настроек нет.
  - Строки UI — по-русски прямо в коде.
