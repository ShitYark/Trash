# Раздел «Терминал»: всё, что поставлено через терминал

## Метаданные

- Дата: 2026-10-12
- Модуль: `terminal` (новый); смежные — `scanning`, `cleanup`, `main-window`
- Статус: выполнен; ревью пройдено. Решение по High: Maven, `~/.cache` и pub-cache показываются, но сами не отмечаются

## DoD

- Пункт «Терминал» в боковой панели, окно как у Xcode: сводка и разделы.
- Разделы из таблицы ниже; у элементов подпись — что это, чем поставлено, версия; явный мусор отмечается сам.
- Удаляются только кэши — файлами внутри `~`. Установленные программы, версии и службы — только поиск.
- Тесты — на JSON-фикстурах и временных папках, запуск `brew` подменён.

| Кэши менеджеров пакетов | Homebrew, npm `_cacache`, Yarn, pnpm, pip, Poetry, Go build, Cargo registry, Maven, pub-cache `hosted`/`git`, `~/.cache` | все | да |

## Этапы

1. **Модель.** `CategoryGroup.terminal`; 7 категорий; новые способы поиска. Системные папки — `SystemLocations` (`/usr/local`, `/Library`, `/Applications`, префиксы Homebrew), подменяются в тестах; корнями категорий не становятся.
2. **Поиск.** `TerminalScanner` + разбор JSON Homebrew; `brew` запускается, только если существует.
3. **Окно группы.** `XcodeOverviewView` → `GroupOverviewView(group:)` для Xcode и Терминала; `SidebarItem.xcode` → `.group(_)`.
4. **Защита.** Удаляемые — только «Gradle» и «Кэши менеджеров пакетов», их корни внутри `~` попадают в `SafetyGuard`; остальное `isDeletable == false`.
5. **Тесты.** Сироты и старые версии Homebrew; образ без AVD; build-tools и Gradle кроме свежей; битая ссылка; служба без программы; активная версия языка не отмечается; без `brew` — «Нет данных»; кэши Homebrew и pip не считаются дважды; корни новых категорий не задевают соседние данные.
6. **Проверка.** `make build`, `make test`; прогон по реальному диску — сверка с разведкой; `make run`.
7. **Документация.** Модуль `terminal`, глоссарий, карта, история.

## Риски из истории и как учтены

- Обобщение окна сохраняет свёрнутые разделы, сортировку, смешанный чекбокс, «отмечено N»; тесты сводки Xcode переводятся на `.group(.xcode)`.
- Без списка AVD или пакетов ничего не отмечается — как у симуляторов.
- Жёсткие ссылки между элементами считаются в каждом — принятое правило.
