## Этапы

1. **Размер.** `CleanupScanner.allocatedSize` считает файл с несколькими жёсткими ссылками один раз внутри элемента: `linkCount` > 1 → учёт по `fileIdentifier`. Остаётся «место на диске».
2. **Боковая панель.** Выбор — `SidebarItem`: категория системы или `xcode`. Плоский список без заголовков секций; у «Xcode» — сумма, спиннер во время скана.
3. **Окно Xcode** — новый `XcodeOverviewView`: сводка; разделы `DisclosureGroup` по убыванию размера; в заголовке иконка, название, размер, чекбокс «выбрать всё» у удаляемых, метка «только поиск» у неудаляемых; внутри — описание, «Нет данных» с причиной или элементы теми же строками, что сейчас.
4. **Не меняется:** выбор по умолчанию, очистка, подтверждение, отсутствие шортката, автоскан.
5. **Тесты.** Жёсткая ссылка считается один раз; сумма и «отмечено» по секции Xcode в view model — только удаляемые.
6. **Проверка.** `make build`, `make test`; повторная сверка с `du` — все разделы в пределах 1 %; `make run`.
7. **Документация.** `main-window` — плоская панель и окно Xcode; `scanning` — жёсткие ссылки; история.

## Риски из истории и как учтены

- «Отмечено M» и чекбоксы разделов — только по удаляемым элементам; неудаляемые не выбираются ни чекбоксом, ни «выбрать всё», ни автосканом.
- «Нет данных» с причиной остаётся и внутри раздела.
- Размер — по-прежнему место на диске; логический размер не вводится.
- Шорткат на «Очистить» и автоскан под тестами не трогаются.
