# Удаление «только поиск», очередь 3: битые ссылки, службы, MacPorts — с паролем администратора

## Метаданные

- Дата: 2026-10-13
- Модули: `cleanup` (основной), `terminal`, `main-window`
- Статус: готово 2026-10-13. Ревью — 2 High, 4 Medium, Low — исправлены; тесты 129/129, мутации ловятся; на диске пользователя скрипт для 15 ссылок и 2 служб собран и прогнан копией с `echo` вместо `rm` — все 17 шагов прошли проверки. MacPorts у пользователя нет — только тесты.
- Решения пользователя при интерпретации: зона удаления выходит за пределы `~` — `/usr/local/bin`, `/Library/LaunchAgents`, `/Library/LaunchDaemons`, MacPorts; шаги от root — `rm` и команды без Корзины. Прежнее «без `rm` с правами администратора» касалось программ и для них остаётся.

## DoD

- Битые ссылки в папках команд удаляются: в своих папках — файлом по режиму, в чужих — `rm` от root. Остальное в «Программах вне Homebrew» — только поиск.
- Службы с удалённой программой: plist без выгрузки службы — в своей папке по режиму, в `/Library` — `rm` от root. Работающие — только поиск.
- MacPorts: неактивные версии — `port -N uninstall <порт> @<версия>`, от root, если папка MacPorts не своя. Сборка и исходники — только поиск.
- Один запрос пароля на очистку; каждый шаг перепроверяется под root; отмена — шаги от root не выполняются.
- Сами не отмечаются; окно очистки и отчёт говорят про пароль и «без Корзины».

## Этапы

1. Модель: разделы удаляемые и сами не отмечаются; `isSearchOnly` у неудаляемого; операция MacPorts.
2. Сканеры: флаги; операция у неактивных версий.
3. Защита: узкие правила стража для ссылок и plist; перепроверки в `Cleaner`; агенты пользователя — `bootout`.
4. Шаги от root: сервис, который собирает один `sh`-скрипт с проверками под root и запускает его через `do shell script … with administrator privileges`; разбор построчного статуса; отмена.
5. Окно очистки и отчёт.
6. Тесты: скрипт исполняется обычным `sh` во временной папке, `launchctl` и `port` подменены.
7. Проверка, документация, история.

## Решения

- Один скрипт на очистку: кэш авторизации по TN2065 — только для того же скрипта.
- По ревью: `osascript` в фоне с тайм-аутом 10 минут вместо `NSAppleScript` на главном потоке — окно не замирает; root — только для фиксированных системных папок; службы не выгружаются.
- `port reclaim` не запускаем: без терминала он молча удаляет и неотмеченное.
- Root — только для фиксированных системных папок без права записи, решается в момент удаления; своя папка без прав — отказ.
