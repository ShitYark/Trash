# Раздел Xcode: поиск всего мусора Xcode и инструментов разработки

## Метаданные

- Дата: 2026-10-12
- Модуль: `xcode` (новый); смежные — `scanning`, `cleanup`, `main-window`
- Статус: выполнен; ревью пройдено, findings Medium закрыты

## DoD

- В боковой панели секции «Система» и «Xcode»; в «Xcode» — все категории из таблицы ниже.
- У каждого элемента понятная подпись: проект, версия iOS, имя симулятора, дата последнего использования.
- Явный мусор отмечается сам — поэлементно, а не только по категории.
- Симуляторы, рантаймы и старые Xcode **только находятся**: чекбокс неактивен, `Cleaner` их отклоняет. Удаление через `simctl` — отдельная задача.
- Тесты на новую логику поиска — только временные папки и JSON-фикстуры; реальный `~` и `xcrun` в тестах не трогаются.

## Категории раздела Xcode

| Категория | Откуда | Подпись элемента | Отмечать сам | Удаление в этой задаче |
|---|---|---|---|---|
| Рантаймы симуляторов | `xcrun simctl runtime list -j` | версия, сборка, последний запуск | `deletable` и не нужен ни одному симулятору | нет — только поиск |

## Этапы

1. **Модель.** `CleanupCategory.group` (`system` / `xcode`); `ScanItem` получает `title`, `details`, `isRecommended`, `isDeletable`. Категории отличаются способом поиска: дети корней / DerivedData / Device Support / архивы / simctl / приложения Xcode.
2. **Поиск.** Новые `XcodeScanner` (DerivedData, Device Support, архивы, старые Xcode), `SimulatorCatalog` (разбор JSON `simctl`), `CommandRunner` (запуск `xcrun`, подменяется в тестах). «Кэши приложений» и «Журналы» пропускают папки, которые являются корнями других категорий, — нет двойного учёта.
3. **Удаление.** `SafetyGuard` разрешает корни только удаляемых файловых категорий — все внутри `~`. Неудаляемые элементы `Cleaner` отклоняет с причиной в отчёте, остальные удаляет дальше.
4. **UI.** Секции с суммой; подпись под именем элемента; неактивный чекбокс и подсказка у неудаляемых; «Выбрать всё» — только по удаляемым.
5. **Тесты.** Разбор фикстур `simctl` (запущенный не рекомендован, сирота найдена, рантайм без симуляторов рекомендован); DerivedData «проекта нет»; самая свежая Device Support не рекомендована; SwiftPM не попадает в «Кэши приложений»; `SafetyGuard` не пускает `/Applications/Xcode*.app` и папки симуляторов; `Cleaner` отклоняет неудаляемое.
6. **Проверка.** `make build`, `make test`; `make run` — только скан, сверка размеров с разведкой `du`. «Очистить» не нажимается.
7. **Документация.** Модуль `xcode`: док, история, глоссарий, карта. `cleanup` — контракт: какие типы удаляются; `scanning` — двойной учёт; `main-window` — секции; запись истории о пересмотре решения по Device Support.

## Решения

- Device Support: прежнее решение «не отмечать по умолчанию» пересмотрено пользователем 2026-10-12 — самая свежая версия остаётся, отладка на текущем устройстве не страдает.
- Удаление симуляторов, рантаймов и Xcode отложено: пользователь попросил в этой задаче только логику поиска.
