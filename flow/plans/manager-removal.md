# Удаление через менеджеры, очередь 1: симуляторы, рантаймы, Homebrew, версии языков

## Метаданные

- Дата: 2026-10-12
- Модули: `cleanup` (основной), `xcode`, `terminal`, `main-window`
- Статус: готово 2026-10-13. Ревью и повторное ревью исправлены; тесты 99/99, мутации новых защит ловятся; холостой `brew cleanup --dry-run` на диске пользователя совпал с отметками по всем 14 формулам. Документация и история модулей обновлены.
- Конфликт с историей разрешён пользователем: «только поиск» был временным; вместо снятой защиты — своя у пути через менеджер

## DoD

- Рантаймы, симуляторы, Homebrew и версии языков можно отметить и удалить.
- Рантаймы — `simctl runtime delete`, симуляторы — `simctl delete`, папки без симулятора — файлами, Homebrew — `brew uninstall` и `brew cleanup`. Версии языков — удалением папки версии внутри `~`, в Корзину или навсегда.
- Отказ до команды: запущенный симулятор, рантайм в работе, активная или неопределённая версия, неверный идентификатор, операция не своего раздела.
- Новые удаляемые разделы сами не отмечаются, явный мусор — с меткой.
- Окно подтверждения предупреждает: через менеджер — сразу, без Корзины.

## Этапы

1. `ManagerRemoval` в элементе — только из вывода менеджера; `ScanItem.isDeletable` — по категории и операции.
2. `ManagerRemover`: фиксированные команды, проверка идентификаторов, свежее состояние, тайм-аут 5 минут.
3. `Cleaner`: путь через менеджер, порядок «симуляторы раньше рантаймов», папки без симулятора — с перепроверкой `simctl`, версии языков — с перепроверкой активности.
4. Категории: `isDeletable`, `isManagerOnly`, `autoSelectsRecommended`, корни версий языков.
5. Сканеры: операции у элементов — рантаймы, симуляторы, Homebrew.
6. Окно: группировка отметок Homebrew по формуле, метка «мусор», «не отмечено», предупреждение в подтверждении.
7. Тесты, проверка, документация.

## Решения

- Новые удаляемые разделы сами не отмечаются: иначе после скана сразу 55,5 ГБ рантаймов, а нужный проекту iOS 15 тоже среди них.
- `brew cleanup <формула>` удаляет все старые версии формулы — отметка группируется по формуле.
- Ненужная зависимость удаляется целиком — `brew uninstall`; версии такой формулы группируются.
- Cask, явно поставленные и закреплённые пакеты остаются только для поиска.
- По ревью: `brew` — с `HOMEBREW_NO_AUTOREMOVE=1`; `brew cleanup` — только после совпавшего `--dry-run`; активная версия — сведением к папкам, несовпадение — «неизвестно»; симуляторы и версии — узкими правилами стража, не корнями; одна кнопка «Удалить через менеджеры», когда всё удаляют они.
