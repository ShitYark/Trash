## Правила

### 1. «failed to produce diagnostic» — разбей выражение на `let` с явными типами

Тайпчекер не смог вывести тип большого выражения и не нашёл, на что пожаловаться. Строка ошибки указывает на начало выражения, а не на виновную часть. Частая причина — тернарный оператор между литералами замыканий прямо в аргументе вызова:

```swift
// Падает компилятор:
self.init(versionFolders: hasVersions ? { load(home) } : { [] })

// Собирается:
let versionFolders: @Sendable () -> [URL] = { hasVersions ? load(home) : [] }
self.init(versionFolders: versionFolders)
```

Литерал замыкания — в `let` с явным типом функции, ветвление — внутри одного замыкания.

## Записи-случаи

#### 2026-10-13 — «failed to produce diagnostic» на `self.init(...)` в `SafetyGuard`

- Симптом: `make build` падает на `SafetyGuard.swift`, ошибка указывает на `self.init(` удобного инициализатора.
- Причина: аргумент `versionFolders:` — тернарный оператор между двумя литералами `@Sendable`-замыканий.
- Правильно: замыкание вынесено в `let versionFolders: @Sendable () -> [URL]`, условие — внутри него.
- Урок: при этой ошибке сначала выносить литералы замыканий и тернарные операторы из аргументов в `let` с явным типом.
