# Главное окно

Единственное окно приложения: своя боковая панель — «Обзор», категории системы, Программы, Xcode и Терминал по одному пункту, — экран выбранного пункта, нижняя панель очистки, окно очистки. Состояние окна — `CleanupViewModel`. Оформление — дизайн «Сортировочная» из холста «Trash — дизайн приложения»: графит, сигнальный оранжевый `#FF8A3D`, окно всегда тёмное.

## Точки входа

- `TrashApp` — `WindowGroup` 1280×860 по умолчанию, минимум 900×560, `preferredColorScheme(.dark)`, акцент — `Theme.accent`.
- `ContentView` — `NavigationSplitView`: боковая панель, экран пункта, нижняя панель внутри экрана, кнопка «Найти мусор заново» в тулбаре, окно очистки, автоскан при появлении.
- `SidebarView` — свои строки-кнопки, а не `List`: знак `BrandMark`, «Обзор», «Система» — Кэши приложений, Журналы, Корзина, Кэши в данных программ, Установщики в Загрузках, «Группы» — `SidebarItem.groups`. Справа в строке — размер, «ищем…» во время скана или замок при отказе в доступе; у группы размер появляется, когда просканированы все её разделы. Внизу — виджет диска: имя тома, полоса «мусор / остальные данные / свободно».
- `OverviewView` — экран «Обзор», открыт при запуске:
  - «Можно освободить сейчас» — `selectedSize`;
  - карточка тома: свободно сейчас и после очистки;
  - «Что занимает диск» — группы, остальные данные, свободное место;
  - баннер Full Disk Access при отказе в доступе, карточки групп с тремя крупнейшими разделами, блок «Ещё N мусора не отмечено» — в каких разделах и что они удаляются без Корзины;
  - во время скана — ход сканирования: «N из 24 разделов», «уже найдено», сетка «готово / ищем», панели групп по разделам.
- `GroupOverviewView` — экран группы, Программы, Xcode или Терминал:
  - сводка «Найдено / Отмечено к удалению / Мусор, не отмечен» — цифры, без графика;
  - разделы-карточки, свёрнуты; в «Терминале» пустые разделы без ошибки скрыты — `visibleCategories(in:)`, а если скрыто всё — «Здесь чисто»; по убыванию размера, а пока идёт скан — в исходном порядке, чтобы раскрытый раздел не уезжал;
  - в заголовке раздела — смешанный чекбокс «выбрать всё», название (клик раскрывает), метка «только поиск», «отмечено N», замок при отказе в доступе, размер или «нет данных» с причиной в подсказке;
  - внутри — описание, баннер Full Disk Access, причина пустоты или строки элементов.
- `CategoryDetailView` — экран категории системы: описание, «Найдено / Отмечено», баннеры, карточка-список с «Выбрать всё».
- `ItemRow` — строка элемента, общая для обоих экранов: чекбокс с именем элемента для VoiceOver, иконка из Finder, `title` и `details`, метки «мусор» и серая «только поиск» — у элемента, который нельзя отметить, размер, кнопка и контекстное меню «Показать в Finder». Без графиков и подсветки наведения.
- `CleanupBar` — «Отмечено к удалению: N» на текущем экране, подпись «на этом экране» или «во всех разделах», кнопка «Очистить».
- Окно очистки — один sheet на весь путь: `ConfirmCleanupSheet` → `CleaningProgressView` → `CleanupReportSheet`.
- `Theme`, `ThemeComponents` — цвета, шрифты, метки, полосы, стили кнопок, карточки.
- `CleanupViewModel+Bindings` — `selectionBinding(for:)` и `selectAllSources(for:)` — источники для `Toggle(sources:)` «выбрать всё», общие для обоих экранов.
- `CleanupViewModel` — `@MainActor @Observable`:
  - `phase` (`idle` / `scanning` / `cleaning`), `results`, `selection: Set<URL>`;
  - `selectedItem: SidebarItem?` — `.overview`, `.category` или `.group`; `SidebarItem.categories` — разделы его экрана;
  - `cleanupScope`, `cleanupItems`, `cleanupSize` — что относится к «Очистить» на текущем экране;
  - `lastReport`, `disk`;
  - `init(scanner:cleaner:diskSpace:)` — для тестов с подменённым сканером и местом на диске.
- `DiskSpace` — объём и свободное место тома из `URLResourceValues`.

## Связанные модули

- `scanning.md` — что и как ищется.
- `xcode.md` — разделы окна Xcode.
- `cleanup.md` — что происходит после подтверждения.

## Ключевые сценарии

- Запуск → «Обзор» → `.task` → `scan()`. Под тестами автоскан отключён: проверяется переменная окружения `XCTestConfigurationFilePath`.
- Скан сбрасывает результаты и выбор и перечитывает место на диске. По мере прихода категорий отмечаются элементы с `isRecommended` и `isDeletable` — кроме разделов, где отмечать решает пользователь (`autoSelectsRecommended == false`): рантаймы, симуляторы, Homebrew, версии языков.
- **Цифры «Обзора»:**
  - «можно освободить» — только выбранное удаляемое, `selectedSize`;
  - «найдено» — `foundSize`, без дублей по URL;
  - «мусора не отмечено» — `unmarkedJunkSize`, явный мусор без отметки: неудаляемый или из разделов, которые сами не отмечаются.
- «Выбрать всё» — `Toggle(sources:)` по удаляемым элементам категории: частичный выбор — **смешанный** чекбокс, а не пустой; в свёрнутом разделе отмеченное дополнительно видно как «отмечено N». У раздела без удаляемых элементов чекбокса нет — пустое место для выравнивания, скрытое от VoiceOver.
- Категория пуста и есть `unavailableReason` — «Нет данных» с причиной вместо «Здесь чисто».
- **Очистка — по текущему экрану.** «Отмечено к удалению», окно очистки и `cleanSelected(permanently:)` берут `cleanupItems` — отмеченное в разделах экрана:
  - «Обзор» — все разделы;
  - категория системы — только она;
  - группа — её разделы.

  Отметки других разделов при переходе сохраняются, но не учитываются и не удаляются; после очистки они остаются отмеченными.
- **Окно очистки.** «Очистить» → подтверждение. Тексты — `CleanupNotes`, только про отмеченное, из `cleanupItems`:
  - подзаголовок «Перед удалением всё проверяется ещё раз: не тронем …» — по видам отмеченного: системные папки и файлы вне разрешённых, запущенные программы, активные версии языков, запущенные эмуляторы Android и нужные им образы, нужные симуляторам рантаймы, включённые симуляторы, нужные другим пакеты Homebrew, base conda, ссылки, которые снова ведут на программу, службы, чья программа снова на месте;
  - разбивка `cleanupItems` по группам — группа элемента та, что видна на экране;
  - плашка — только про то, что уходит не по выбранному режиму: кто удаляет сразу и без Корзины — `simctl`, `brew`, `docker`, `conda`, Ollama, а битые ссылки, службы в `/Library` и порты MacPorts — с паролем администратора; папки без симулятора — файлами, по режиму; «содержимое Корзины — навсегда»; «программы — только в Корзину». Нечего сказать — плашки нет;
  - две кнопки-карточки «Переместить в Корзину» и «Удалить навсегда». Подписи называют исключения из отмеченного: «можно вернуть, кроме удалённого через simctl, conda или Ollama и содержимого Корзины» — только инструменты отмеченного, «вернуть будет нельзя — кроме программ».
  - Всё отмеченное удаляется навсегда при любом режиме — менеджерами или как содержимое Корзины — одна кнопка «Удалить», «Сразу, без Корзины»: выбора нет, и «можно вернуть» было бы неправдой. Она передаёт режим «в Корзину» — на случай, если сюда всё же попадёт обычный файл.

  Дальше `cleanSelected(permanently:)` → ход очистки → отчёт в том же окне:
  - освобождено и куда ушло удалённое — по счётчикам `CleanupReport`, а не по выбранному режиму: в Корзину, навсегда, сразу и без Корзины — через менеджер. Одно направление — фразой без чисел, несколько — по строке с числом;
  - до трёх причин отказа и «…и ещё N» — с именем строки из списка, а не файла: у строк Docker путь — диск;
  - «Готово».

  Удалённое убирается из `results` и `selection`, место на диске перечитывается.
- **Один элемент в двух разделах** — программа Xcode в «Установленных программах» и «Старых версиях Xcode»: выбор общий по URL, `selectedItems`, `cleanupItems` и `foundSize` без дублей. Копия входит в область обоих экранов и удаляется с любого из них.
- **Окно группы:** «Отмечено к удалению» — `selectedSize(in: group)`, по разделу — `selectedSize(in: category)`, только выбранные удаляемые элементы. Чекбокс заголовка свёрнутого раздела отмечает всё удаляемое в нём, включая элементы, которые не отмечаются сами, — например архивы.
- **Неудаляемые элементы** — разделы Android SDK, программы и службы Терминала, Docker, conda, MacPorts, Ollama, а в рантаймах и Homebrew — элементы без операции менеджера: встроенный рантайм, cask, явно поставленная или закреплённая формула. Чекбокс неактивен, `setSelected` их не добавляет; явный мусор помечен меткой «мусор». Метка раздела «только поиск» — только у неудаляемого раздела.
- **Связанные отметки Homebrew.** Элементы одной операции `brew` (`ManagerRemoval.isGrouped`) отмечаются и снимаются вместе: `brew cleanup <формула>` и `brew uninstall --force` удаляют все такие версии разом.
- Баннер Full Disk Access открывает `x-apple.systempreferences:com.apple.preference.security?Privacy_AllFiles`.

## Нюансы

- Пока идёт скан или очистка, повторный запуск игнорируется (`phase != .idle`), кнопки неактивны; окно очистки во время очистки не закрывается.
- **Шорткаты.** У «Очистить» и у кнопок удаления в окне очистки нет клавиатурного шортката — **намеренно**: двойной Return не должен удалять файлы. «Отмена» — по Esc, «Готово» в отчёте — по Return.
- **Окно очистки одно** — **намеренно**. Второй sheet после закрытия первого мог не открыться, если очистка закончится быстрее анимации; тогда `isReportPresented` залипал бы.
- **Место на диске.** `URL` кэширует значения ресурсов, поэтому `DiskSpace.current(for:)` сбрасывает кэш перед чтением — иначе после очистки остаётся место на момент запуска. Свободное место — `volumeAvailableCapacityForImportantUsage`, с учётом того, что macOS освободит сама, как в Finder.
- **Списки быстрые за счёт трёх правил:**
  - `ItemRow` получает значения — `isSelected` и `onToggle`, — а не `Binding` и сравнивается через `==` по элементу и отметке (`.equatable()`). Щелчок по отметке перерисовывает одну строку, после скана или очистки строка обновляется — сравниваются все поля `ScanItem`. Новое поле, от которого зависит `body`, обязано попасть в `==`.
  - Список явно читает `model.selection` и передаёт строке `selection.contains`: так строки обновляются и после «выбрать всё» в заголовке на любой версии macOS.
  - Иконки Finder — из кэша `FileIcons` по пути: с диска читаются один раз.
- **Графиков на экранах разделов нет — намеренно:** пользователь назвал полосу состава группы и полоски размера в строках непонятными. Полосы остались только на «Обзоре», в карточках групп и в виджете диска — там они с подписями.
- «Остальные данные» на полосе диска — занятое место минус всё найденное. Что из них приложение научилось находить и что не трогает — `scanning.md`.
- **Шрифты системные:** SF Pro, SF Pro Rounded для крупных цифр, SF Mono для размеров. Шрифты холста — Unbounded, Onest, JetBrains Mono — пользователь решил не встраивать.
- **Боковая панель — свои кнопки.** Стрелки ↑/↓ пункты не переключают, с клавиатуры панель доступна только при Full Keyboard Access — цена точного вида из дизайна.
- **Иконка приложения** — вариант А «Бак с полосами»: PNG в `AppIcon.appiconset` нарисованы скриптом на CoreGraphics. 16 и 32 px упрощены. Скрипт лежал в `tmp/app-icon/` и в репозиторий не входит. Если Dock показывает старую иконку — это его кэш: помогает `lsregister -f` для приложения или перезапуск Dock.
- Строки UI — по-русски прямо в коде, каталога локализации пока нет.
- `#Preview` у `ContentView` тоже запускает автоскан реального диска — только чтение.
