# Workflow: artifacts (под-рутина)

Проверь, нужны ли для задачи debug-артефакты, и при необходимости получи их или попроси. Применяется как шаг в `/dev:code`, `/dev:search`, `/dev:review`, `/dev:analyze`.

## Триггер

Сканируй сообщение пользователя на эти слова и расширения:

| Категория | Слова и расширения |
|---|---|
| **Краш-репорты** | `crash`, `краш`, `вылетает`, `падает`, `*.ips`, `*.crash` |
| **Логи** | `лог`, `log`, `Console`, `*.log` |
| **UI-артефакты** | `скриншот`, `screenshot`, `видео экрана` |
| **Пути и содержимое папок** | `удалил не то`, `пропал файл`, `не видит папку`, `не находит`, `размер не совпадает` |

Совпадений нет — пропусти шаг полностью.

## Где искать

- **`Debug/`** в корне проекта — сюда пользователь кладёт файлы. Папка в `.gitignore`, очистка — на пользователе.
- **Краш-репорты нашего приложения** агент находит сам, только чтение: `ls -t ~/Library/Logs/DiagnosticReports/ | grep -i '^Trash'`.
- **Листинг папки** — только чтение: `ls -la <путь>`, `du -sk <путь>`. Ничего не удалять и не перемещать.

## Алгоритм при совпадении

1. Прочитай `Debug/` (`ls Debug/`) и, для краша, папку DiagnosticReports.
2. Сопоставь упоминание с файлами:
   - **точное совпадение** → используй, сообщи в сводке шага;
   - **несколько подходящих** → покажи список, спроси, какой использовать;
   - **один файл, но старый** → спроси, актуален ли;
   - **нужного нет** → определи «критично или полезно».

## Критерий «критично или полезно»

| Уровень | Когда | Действие |
|---|---|---|
| **Критично** | без артефакта работа не имеет смысла: краш без краш-репорта; «удалил не то» без пути или листинга; UI-баг без скриншота, который не воспроизводится по описанию | **Остановиться**, попросить положить файл в `Debug/` или назвать путь |
| **Полезно** | есть код и описание, артефакт лишь ускорил бы анализ | **Продолжить** с пометкой «работаю без X, риски Y» |

## Формат запроса при отсутствии критичного артефакта

```text
Для этой задачи критически нужен артефакт:

Тип: [краш-репорт / лог / скриншот / путь или листинг папки]
Что упомянуто: [цитата]
Почему критично: [одно предложение]

В `Debug/` сейчас:
- [список файлов или «пусто»]

Положи файл в `Debug/` или назови путь — я продолжу.
```
